# Lumen Notes (Astro)

Blog built with Astro content collections and deployed to GitHub Pages.

- Posts: `src/content/blog/<slug>.md` (schema in `src/content.config.ts`)
- Static files: `public/` (post hero images in `public/images/`)
- Live site: https://darioghtest.github.io/paragraph-astro-test/blog/

```sh
npm install
npm run dev
```
